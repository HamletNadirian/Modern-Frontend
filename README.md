### Додаток для управління фільмами
Веб-додаток для управління фільмами та продюсерами з підтримкою багатомовності (англійська та українська мови).

### Встановлення

Клонуйте репозиторій:

```
git clone <repository-url>
cd ui-base-app-next-main
```
2. Встановіть залежності:
```
npm install
```
3. Запустіть додаток у режимі розробки:
```
npm start
```
4. 🔗 Маршрути додатку

#### Фільми

+ Список фільмів: http://localhost:3050/movies?lang=ua
+ Деталі фільму: http://localhost:3050/movie/movie-1?lang=ua
+ Створення фільму: http://localhost:3050/movie/new?lang=ua

#### Продюсери

+ Список продюсерів: http://localhost:3050/producers?lang=ua
+ Деталі продюсера: http://localhost:3050/producer/producer-1?lang=ua
+ Створення продюсера: http://localhost:3050/producer/new?lang=ua

#### 🎬 Опис
Повнофункціональний додаток для управління каталогом фільмів та продюсерів. Дозволяє створювати, переглядати, редагувати та видаляти записи зі зручною фільтрацією та пагінацією.
#### ✨ Основні можливості
Управління фільмами

+ 📋 Перегляд списку фільмів з пагінацією (10 елементів на сторінці)
+ ➕ Створення нових фільмів
+ ✏️ Редагування інформації про фільми
+ 🗑️ Видалення фільмів
+ 🔍 Фільтрація за:

  + Назвою фільму
  + Іменем продюсера

#### 💾 Зберігання даних
У поточній версії додатку використовується in-memory сховище (масиви в пам'яті додатку). Дані:

Генеруються при запуску додатку (50 фільмів та 50 продюсерів)
Зберігаються протягом сеансу роботи додатку
Скидаються при перезавантаженні сторінки

Ініціалізація даних
При запуску створюється:

50 фільмів з ID від movie-1 до movie-50
50 продюсерів з ID від producer-1 до producer-50
Автоматичний зв'язок фільмів з продюсерами

🐛 Відомі обмеження
Дані не зберігаються між сеансами (in-memory storage)
Немає серверної частини - всі операції виконуються локально
Затримка у 300-500мс додана штучно для імітації API запитів

Примітка: Це навчальний додаток, призначений для демонстрації роботи з React та Redux. Для production використання необхідно додати серверну частину та реальне сховище даних.
